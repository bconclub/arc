## Rules it follows

1. **One metaphor carries the whole video.** Every item = one more plug, so the progress counter is the retention hook.
2. **Each item gets the same 3 beats:** name + plug-in, feature card, 2 to 4 capability ticks synced to words.
3. **Visual changes every ~1.5 to 2s**, but the frame never resets (strip, avatar, HUD stay put).
4. **Accent type rule:** only nouns and verbs that carry meaning go red serif. Everything else stays black.
5. **Real proof props:** install counts, GitHub stars, real repo names. Credibility props, not decoration.
