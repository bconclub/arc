## Rules it follows

1. **Three-state layout** (full face / split / full graphic) switched every 1 to 3s. Never static.
2. **Item intro = full takeover tile**, then split for explanation. The viewer always knows which item they're on.
3. **Every claim gets a real prop** (provider grid, token budget, star chart). Numbers on screen, not just spoken.
4. **Two typefaces = two voices:** sans for running speech, italic serif caps for emphasis words.
5. **Same hook template as 001** ("Don't use Claude Code unless you've installed these N plugins"). This is a format meme in the AI-creator niche.
