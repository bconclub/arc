## Rules it follows

1. **Result before method.** The first 7s is pure payoff from 4 recognisable brands.
2. **Famous brands as demo material** borrow attention (Nike, AirPods, North Face).
3. **"Save this post" at 7s**: saves are the target metric, not comments.
4. **Proof the process is easy:** one upload, one prompt, one click, shown on real UI.
5. **The loop:** the file is the edit twice, so a replay looks seamless and watch time doubles.
