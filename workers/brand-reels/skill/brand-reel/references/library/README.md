# Reel reference library

Each reel gets a folder: `NNN-creator-topic/` with `source.mp4`, contact sheets, `transcript.txt`, `breakdown.md`.

Add new categories as reels arrive. Split when 3+ reels share a pattern the parent doesn't capture.

## Tag axes (every breakdown)

- **Format:** explainer, tutorial, ad, brand film, UGC, talking head, demo
- **Structure:** listicle, before/after, problem-solution, story, POV
- **Presenter:** none, face cam, avatar, hands, VO only
- **Visual system:** palette, type pair, background, HUD
- **Hook type:** warning, claim, question, visual shock
- **CTA mechanic:** comment keyword, link, follow, none
- **Build method:** code (HTML/Remotion), AE, AI gen, filmed, mixed
