## Formats that work (from Z's references)
- **AI-ad tutorial:** the ad itself in the first second + the real prompt/inputs on screen + "Comment X for the prompt".
  Variants: the prompt reveal (split steps) and the **cards board** (Z's favourite: title, big video card, storyboard
  card, prompt card, serif CTA).
- **Product texture reel:** one hero texture (a cheesecake crushed, chocolate oozing) with real physics, minimal text.
- **Ingredient press / machine:** a press that turns the product's real ingredients into it in one continuous move.
- **Keyframe morph chains, one-product-nine-views grids, sculptural morphs, pop-art collage.**
- **Famous product dropped into a real local place** (Tesla Roadster wave, Oct 2026): "Tesla in India" (8K+ likes in
  an hour), "Day 1 of owning a Roadster: toll booths are optional" (one annoyance beaten by flying). It works because
  of a wanted product + a known place + a joke only locals get + the creator's face. The Brazil gag-list version with
  no local angle did 7x worse.
- **Collision + macro slow-mo** of each object mid-air (branded cup as hero) and the **fixed in-car POV grab**: used for
  the craving reel (a person, not a monkey; the "valuable" thing should be something people crave).

## How to log a new reference
1. Open it in the BCON browser (or the app's own browser if logged-out viewing works); read the caption, likes,
   comments, date, audio.
2. Step through the video (seek the `<video>` and screenshot) and write the beats with timestamps.
3. Write why it works (product truth + mechanic), what we'd translate it into, and which brand it fits.
4. Add it to `REFERENCE-REELS.md` (or tell Insta Deamon) and commit.
