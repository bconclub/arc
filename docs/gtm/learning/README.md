# GTM learning: how we sell PROXe and BCON

Everything the GTM agents (Council, Axlrate PROXe GTM, PROXe Core, PROXe Ads, and any autonomous sales/outreach agent)
have decided or learned about selling, in one place. The founder (Z) makes the calls; this folder is where they land so
any agent, on any machine, can pick them up. Sister folder: [`../../studio/learning/`](../../studio/learning/README.md)
(video and creative).

Started 2026-10-25 by the Council session.

## Source of truth, in order
1. **ARC Supabase `arc_context.gtm_brief`** (offer, buyer, win, motion, channels, truth, rules) and **`gtm_plans`**
   (icp, pain, research, landing, outbound, content, ugc, seo, ads). If anything here disagrees with the brief, the
   brief wins, and the agent tells Z.
2. **This folder** for the reasoning, the decisions behind the brief, the numbers and Z's corrections.
3. **ARC `investor_updates`** for what actually happened (revenue, closures, demos).

## Keeping this current
- When Z decides or corrects something, add it dated (newest first) to the right file, and say whether it replaces an
  older line. Never silently delete history; mark it "superseded by ...".
- Numbers must name their source and date. Label estimates as estimates.
- House style: plain English, no em dashes, no invented numbers.
