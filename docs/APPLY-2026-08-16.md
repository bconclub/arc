## 2. Vercel environment variables (arc project)

| Var | Why |
|---|---|
| `CRON_SECRET` | Nightly invoice scan 503s without it. Any long random string; Vercel Cron sends it automatically once set. |
| `ARC_INGEST_SECRET` | Agent queue (`/api/agent/*`) and PROXe briefs fail closed without it. |
| `OCR_ENABLED=1` | Optional: turns on tesseract OCR for photographed invoices. |
| `ANTHROPIC_API_KEY` | Optional: Haiku fallback for unreadable documents and chat parsing. Everything works without it; the free rungs carry the load. |

## 3. Optional seeds (run locally, once, after the SQL)

```bash
node scripts/seed-brands-history.mjs   # BCON_OP history: 72 brands, 325 receipts
node scripts/seed-content-brain.mjs    # content brain defaults
```

The history seed should be checked against the billing vault afterwards —
both describe the same past and overlaps are expected.
