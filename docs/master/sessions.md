# The sessions

Snapshot of 2026-11-02. Titles change, so check the app's session list before relying on this. `local_` ids are how you
reach a session.

## Reaching a session
- Use `SendMessage` to the `local_...` id. Name-based pings got held across permission modes.
- "Not delivered within 20s" is normal. Slow sessions still wake. Check its last activity before calling it failed.
- A nudge is sometimes needed: one brief went idle with no reply the first time.
- Another session's report is its claim, not proof. Check the file or diff before telling Z it's done.
- Starting a session with no new work: tell it "no new task, reply with a one-line status, wait for Z".
